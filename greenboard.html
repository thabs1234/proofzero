ProofZero — Evidence Board

Finite, runnable checks for ten hard problems. A verified prefix is evidence, never a proof. This board reports only what a command in this repository actually did, plus published bounds it cites without reproducing.
Read the two strongest states as different things. Run here means a tool in this repo executed and its output is reproduced by make verify in CI. Cited, not reproduced means a published result named for reference — this repository did not establish it, and the scale gap to the local run is often many orders of magnitude. No finite check is a deliberate absence, not an oversight: for those problems, computation is not the right tool.
