# Notes

Personal working notes — questions, dead ends, and reading notes that do
not belong to a specific problem file.

Convention used here: anything that is an established theorem, a precise
partial result, or a specific numerical claim carries a citation. Anything
that is a hunch, a heuristic, or an unverified impression is labelled as
such in the sentence itself.

Current contents: none yet. Add one file per topic, named
`YYYY-MM-DD-short-topic.md`.
